🎓 WAD Project Viva Explanation Summary

ClubSphere connects client-side HTML, CSS, and JavaScript with an Express.js backend. The server serves static files using express.static('public') and processes REST API requests (GET and POST) using body-parser middleware (express.json() and express.urlencoded()).

1. Static Serving

app.use(express.static('public')) serves HTML, CSS, and JS directly.

2. Fetch GET Request

fetch('/api/clubs') fetches records dynamically without reloading.

3. Form POST Request

fetch(..., {method: 'POST'}) sends JSON to Express.
