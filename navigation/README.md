# ClubSphere Navigation Preview

A standalone preview of the ClubSphere student navigation. It uses the same purple palette, responsive mobile menu, active-page styling, notification badge, and light/dark theme toggle.

## Run

From the project root:

```sh
npm run start:navigation
```

Or run the server directly:

```sh
node navigation/app.js
```

Then open [http://127.0.0.1:4174](http://127.0.0.1:4174). Set the `PORT` environment variable to use another port.

The preview server uses only Node.js built-ins and runs independently from the main ClubSphere application server.
